## Тестовый стенд (ai-test) — сначала проверка, потом выкатка

Рядом с этой папкой лежит `..\ai-test` — копия проекта для проверки в **тестовом боте** (свой токен в её `.env`,
своя база, временный туннель; см. `ai-test\README-TEST.md`).

- Новые правки сначала делаются и запускаются в `ai-test` (`start-test.ps1`), владелец смотрит их в тестовом боте.
- Пока владелец не написал «выкатывай» / «выкатую», в эту (боевую) папку не пишем и в `main` не пушим.
- «Выкатывай»: `ai-test\promote.ps1` переносит код сюда → `npx tsc -b`, `npx vitest run --exclude "src/lib/gameSim.test.ts"` → коммит → пуш в `main`.
- Исключение: если владелец прямо сказал не использовать стенд для конкретной мелочи.
- Токены только в `.env`; тестовый бот в боевой папке и в коде не используется.
